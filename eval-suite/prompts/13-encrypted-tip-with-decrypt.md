Build an `AnonymousFeedback` contract where users submit encrypted scores 1–5 via `submitScore(externalEuint8, bytes proof)`. The contract maintains an encrypted euint32 running sum. The owner can call `requestAverage()` to trigger an async-decryption flow that reveals the sum (and a plaintext counter of submissions) so the average can be computed off-chain. Use the delete-before-effects callback pattern.
