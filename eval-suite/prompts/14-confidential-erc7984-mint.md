Implement a complete ERC-7984-compatible confidential token contract `cUSD` with: encrypted `euint64` balances, `mint(address, externalEuint64, bytes)` admin function, `confidentialTransfer` and `confidentialTransferFrom` (with allowance via per-pair `mapping(address => mapping(address => euint64)) _allowances`), and `confidentialApprove`. Apply transient ACL on transient-handle returns; persistent ACL on storage. Silent-failure-safe transfers.
