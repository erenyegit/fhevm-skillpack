Build an FHEVM Solidity contract called `PrivateCounter` that holds an encrypted `euint64` counter. Expose `increment(externalEuint64 enc, bytes calldata proof)` and `getCount() returns (euint64)`. Use the modern `@fhevm/solidity` v0.11 API and inherit from `ZamaEthereumConfig`. Make sure every encrypted storage write is followed by `FHE.allowThis` and the caller can decrypt their view of the counter.
