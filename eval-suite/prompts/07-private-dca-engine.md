Build a `ConfidentialDCA` contract. Owner deposits encrypted cUSD and configures an encrypted per-tick swap size via `configure(externalEuint64 encDeposit, externalEuint64 encTick, bytes proof)`. A keeper calls `tick()` once per `TICK_INTERVAL` (1 day). Each tick swaps the encrypted tick size for cETH via a confidential DEX adapter — apply transient ACL to the swap-amount handle. Skip the swap (no-op via `FHE.select`) if balance is insufficient.
