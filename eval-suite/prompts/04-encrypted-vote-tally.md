Build a `ConfidentialVote` contract: each voter submits an encrypted choice (0 or 1) via `vote(externalEuint8, bytes proof)`. The contract maintains an encrypted `euint32` running yes-tally. Prevent double-voting via a plaintext `mapping(address => bool) hasVoted`. After `closeTime` and a 12-block finality delay, expose a `reveal()` function that calls `makePubliclyDecryptable` on the tally.
